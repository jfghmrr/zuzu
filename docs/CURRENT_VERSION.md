# Текущая версия — 13 сентября 2026

## Изменения

- Нативный iOS-проект с CocoaPods; открывать `mobile/ios/Runner.xcworkspace` после `flutter pub get` и `pod install`.
- Оригинальные логотипы, заполнитель фотографии и иконки Figma, Noto Sans с лицензией OFL.
- Отдельное приветствие, формы регистрации и входа, подтверждение кода, два шага первичного заполнения профиля.
- Профиль владельца и переход к питомцу, обновлённые лента, чаты, карта, нижняя навигация и боковое меню.
- Счётчик комментариев учитывает удаление и блокировки; фото владельца доступно для парных аватаров.
- Эталоны Figma и прочитанные свойства сохранены в `docs/design`, контрольные изображения Flutter — в `mobile/test/goldens`.

## Проверено

- 15 серверных тестов.
- 11 Flutter-тестов, включая сохранение вида питомца, переходы, формы и увеличенный шрифт.
- Предыдущая нативная сборка успешно установлена и запущена на iPhone 17 Pro / iOS 26.5; нативная проверка Keychain и инициализации плагинов проходила.
- Расширенный нативный тест для текущего редизайна добавлен, но ещё не запущен. Его наличие не означает успешную проверку текущих экранов на устройстве.

## Остаётся до полной приёмки

Полная сверка всех экранов с Figma и нативный прогон текущего редизайна. Некоторые вторичные формы ещё используют общие компоненты. Карта использует реальные OpenStreetMap-тайлы; автоматические источники заводов и строек относятся к P1. Поле «Вид питомца» добавлено в форму согласно спецификации, хотя его нет в показанном макете. Третий повторяющийся пункт согласия в макете регистрации заменён согласием с условиями использования.

Реальная доставка SMS/email, Firebase/APNs, подписанный релиз на физический iPhone и production-развёртывание требуют настройки внешних сервисов. Локальный режим показывает DEV-код. Сборка APK ещё не проверена: Android SDK не установлен.

## Android

Установить Android Studio для Mac с Apple chip: https://developer.android.com/studio . Через SDK Manager установить Android SDK Platform API 36, SDK Platform-Tools, Build-Tools, Command-line Tools и Android Emulator. Для виртуального телефона выбрать ARM64 system image. При запросе сборки установить NDK 28.2.13676358. Используется JDK из Android Studio.

После установки: `flutter doctor --android-licenses`, `flutter doctor`, затем `flutter run -d <emulator-id> --dart-define=API_URL=http://10.0.2.2:8000`.
