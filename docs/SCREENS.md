# Реестр экранов

Источник каждого пункта — текст задания; Figma недоступна. Для всех node-id неизвестен; известен только корень `0:1`. Точные вложенные панели и prototype links требуют сверки после доступа. Приоритет всех перечисленных экранов P0.

Общие состояния: сетевые loading/empty/content/error+retry; формы editing/invalid/submitting/success/error, сохранение черновика в памяти при сетевом сбое; разрешения granted/denied/restricted по платформе. Это реестр требований, не отчёт о выполнении.

| Экран | Поля/назначение | Действия и переходы (выведены) | Figma node |
|---|---|---|---|
| Приветствие | Логотип, объяснение | Начать → контакт | Неизвестен |
| Контакт | Email/телефон, согласия | Получить код → OTP; документы | Неизвестен |
| Код | 6 цифр, срок, повтор | Вход → незавершённый профиль | Неизвестен |
| Владелец | Фото, имя, фамилия, id, подпись | Сохранить → питомец | Неизвестен |
| Питомец | Фото, вид, кличка, id, порода, город, возраст | Сохранить → профиль | Неизвестен |
| Свой профиль | Парные аватары, счётчики, публикации | Редактировать, ветпаспорт, друзья, напоминания | Неизвестен |
| Чужой профиль | Данные питомца и владельца | Подписка, заявка, чат, блокировка, ссылка | Неизвестен |
| Лента | Истории, посты, поиск, уведомления | Обновить, пагинация, создать, открыть | Неизвестен |
| Публикация | Текст, 1–8 фото | Выбор, удалить вложение, сохранить | Неизвестен |
| Пост / фото | Карусель, полный текст | Лайк, реакции, комментарии, удалить своё | Неизвестен |
| Комментарии | Текст, ответы, реакции | Ответ, лайк, жалоба, удаление | Неизвестен |
| Жалоба | 3 причины, описание | Подтверждённая отправка | Неизвестен |
| История | Фото, подпись | Камера/галерея, публикация | Неизвестен |
| Просмотр истории | Фото, автор, срок | Лайк, ответ в чат, просмотры, удаление | Неизвестен |
| Поиск | Кличка/id | Debounce, сброс, ещё, профиль | Неизвестен |
| Друзья | Друзья, подписки, заявки | Принять, отклонить, отменить, удалить | Неизвестен |
| Чаты | Собеседник, последнее, непрочитанные | Поиск, открыть диалог | Неизвестен |
| Диалог | Сообщения, фото, статусы | Отправить, повтор, история страницами | Неизвестен |
| Ветпаспорт | Рост/вес/пол/возраст, записи | Добавить, открыть запись | Неизвестен |
| Ветзапись | Тип, дата, диагноз, рекомендации, фото | Сохранить, редактировать, удалить, напомнить | Неизвестен |
| Напоминания | Календарь, выбранный день, ближайшие | Создать, выполнить, перенести, удалить | Неизвестен |
| Напоминание | Название, дата/время, пояс, заметка, задачи | Сохранить, уведомления | Неизвестен |
| Карта | Тайлы, точки, область | Ручной выбор, геолокация, фильтры | Неизвестен |
| Метка | Тип, описание, координаты, статус | Добавить, обсуждать, закрыть, удалить | Неизвестен |
| Местные новости | Город/точка, заголовок, текст | Добавить, открыть автора | Неизвестен |
| Уведомления | Прочитано/непрочитано, цель | Заявка/напоминание/чат | Неизвестен |
| Меню | Навигация по инструментам | FAQ, поддержка, настройки | Неизвестен |
| Обратная связь | Имя, email, текст | Отправка → сервер | Неизвестен |
| FAQ | Раскрывающиеся ответы | Открыть/закрыть | Неизвестен |
| Настройки | Уведомления, блокировки, документы, лицензии | Сохранить, выход, удалить аккаунт | Неизвестен |
| Чёрный список | Заблокированные | Разблокировать | Неизвестен |
| Подтверждения | Выход, удаление, отключение | Отмена / подтверждение | Неизвестен |
