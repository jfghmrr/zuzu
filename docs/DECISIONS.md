# ЗуЗу — решения и границы проверки

Источник: пользовательский `zuzu-mvp-prompt.md`, ссылка Figma https://www.figma.com/design/mp1JPrypjUQ8GXkjNweG62/ЗуЗу?node-id=0-1 . 13 сентября 2026 инструмент Figma отказал: «Looks like you don't have edit access to this file». Страницы «Готовое»/«Рабочка», дочерние node-id, компоненты, шрифты, точные цвета, ассеты и связи прототипа **не прочитаны**. Реестр ниже основан на текстовой спецификации. Все переходы — вывод из неё. Цвета временные, визуальное совпадение не подтверждено.

## Навигация и первый сценарий

Пять постоянных вкладок: Профиль → Лента → Чаты → Карта → Меню. Ветпаспорт, напоминания и друзья доступны из профиля и меню. Первый вертикальный сценарий: одноразовый код → имя владельца и единственный питомец → приватная ветзапись с изображениями → напоминание → перезапуск и повторное чтение с сервера.

## Принятые обратимые допущения

- Основной контакт подтверждается кодом. Второй привязывается только после отдельной проверки в существующей сессии. Автоматического объединения аккаунтов по непроверенным данным нет.
- Один питомец на владельца; вид произвольный, порода необязательна. Приблизительный возраст хранится в месяцах вместе с датой оценки; при отображении прибавляются прошедшие календарные месяцы. Дата рождения и оценка взаимоисключающие.
- Социальные связи между account_id. Pet.id никогда не используется как account_id.
- Хронологическая лента своих постов и подписок. История живёт 24 часа. Любой вошедший пользователь может начать личный чат, если нет блокировки.
- Временные границы уровня: 0–1, 1–3, 3–6, 6–24, 24+ календарных месяцев. Достижения: действующие посты + метки; уровень не подтверждает квалификацию.
- До согласования политики удаления локальная реализация удаляет публичный контент, диалоги аккаунта целиком и приватные данные автора, включая медиа. Это продуктовое решение требует согласования перед выпуском.
- Напоминания однократные, сервер хранит UTC и IANA timezone; локальные уведомления на каждом устройстве, социальные push — отдельно. Внутренний список не вызывает повторную системную доставку.
- Новость привязана к точке и городу; область выдачи — видимый прямоугольник карты. Промышленные/строительные объекты вводятся только модератором, внешней базы нет.
- Лимиты: 8 фото на запись, 10 MiB на фото, 5000 символов поста, 2000 комментария/сообщения. Изображения сервер декодирует, нормализует в JPEG, удаляет метаданные.

## Технический выбор

Flutter/Dart — общая клиентская база iOS/Android, web только для доступной локальной проверки. FastAPI + SQLAlchemy, PostgreSQL для развёртывания, SQLite для воспроизводимой локальной проверки без работающего Docker. Права проверяются серверным слоем на каждом API и при чтении файла; БД напрямую клиенту недоступна. Supabase рассмотрен, но поставщик и регион не выбраны без географии и правил размещения. Структура не привязывает продукт к SaaS.

Сессии — случайные непрозрачные токены, в БД только SHA-256; мобильный клиент использует защищённое хранилище. OTP хранится хешированным с солью challenge-id, сроком, счётчиком попыток и cooldown. В локальном режиме код возвращается явно как DEV-код; production не допускает этот режим. Реальная доставка через серверный webhook-адаптер с секретом. Клиент не получает ключи провайдера.

## Матрица прав

| Данные | Владелец | Другой аккаунт | Модератор |
|---|---|---|---|
| Публичные профили, посты, истории, карта | CRUD | Чтение при отсутствии блокировки, разрешённые реакции | Скрытие контента с журналом |
| Контакты, ветзаписи, их файлы, напоминания, настройки | CRUD | Нет | Нет через пользовательский API |
| Сообщения/фото | Участники диалога; отправитель удаляет своё | Только участник, без блокировки | Жалоба и действие по содержимому жалобы |
| Просмотры истории | Автор читает список | Читатель фиксирует только себя | Не требуется |
| Заявки | Отправитель отменяет; получатель принимает/отклоняет | Нет | Не требуется |
| Жалобы, обращения | Создание | Нет | Защищённый API обработки и журнал |

## P1

Видео постов/историй; рисование, шрифты и редактор историй; массовая пересылка; онлайн и общие друзья; рейтинг; повторяющиеся напоминания; PDF; автоматические внешние объекты карты. Источники — соответствующие разделы 3.3–3.12 текстового задания; точные node-id неизвестны.

## Среда сборки

В начале Xcode был недоступен через xcode-select; в ходе работы обнаружен Xcode 26.6. Его компонент iOS 26.5 не установлен, доступных устройств/симуляторов нет. flutter build ios --no-codesign остановился до компиляции приложения. Для плагина secure storage подготовлен CocoaPods-путь (Flutter config только этого проекта); глобальные настройки Flutter не менялись. Причина отсутствия build settings подтверждена xcodebuild -showdestinations: iOS 26.5 is not installed.

Начальный центр карты — Москва как демонстрационная стартовая область, а не определённое местоположение пользователя. Геолокация запрашивается только кнопкой; город пользователя вводится явно.
